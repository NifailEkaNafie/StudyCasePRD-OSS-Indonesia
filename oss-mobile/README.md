# OSS Indonesia Mobile App (Vibe Code — Hanya PRD)

Aplikasi web mobile **OSS Indonesia** yang dibangun menggunakan **React + Vite** berdasarkan spesifikasi **Product Requirements Document (PRD)** dari hasil riset **Worksheet 1–8** (Nifail Eka Nafie - 202310370311344).

## Fitur Utama (Sesuai Worksheet 8)

1. **UX-01 (P1 - Tinggi)**: *In-App PDF Viewer* pada halaman Detail Regulasi untuk membaca lampiran regulasi secara langsung.
2. **UX-02 (P2 - Sedang)**: Fitur *Unduh Dokumen PDF* dan opsi *Buka melalui Aplikasi Pembaca PDF Lain*.
3. **UX-03 (P2 - Sedang)**: Pesan kesalahan yang jelas menggunakan bahasa sederhana (menggantikan error teknis `403: Authentication failed`) disertai tombol **Coba Lagi** dan **Unduh Dokumen**.
4. **UX-04 (P3 - Rendah)**: Identitas nama dokumen, ukuran berkas, dan badge format file **`PDF`** pada daftar lampiran regulasi.

## Menjalankan Aplikasi

```bash
npm install
npm run dev
```
